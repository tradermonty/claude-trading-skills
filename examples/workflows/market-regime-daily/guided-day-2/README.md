# Guided day-2 fictional fixtures

Fictional component fixtures for the guided runner's second day, evaluated at
`2026-01-16T13:08:00+00:00` with every input dated `2026-01-15T21:00:00+00:00`.
Select them with `--fixture-set day-2` when creating a run. They give the
decision diff a genuinely newer day to compare against day 1.

This is not a replay variant: it has no `replay.yaml`, no golden output, and is
not listed in `replay-coverage.yaml`. The day-1 replay contract is unchanged.
The values are not market data and not a trading signal.
